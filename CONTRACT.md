# Implementation contract (internal)

Pure Swift package `PhaseCore` at repository root, sources Sources/PhaseCore; iOS 17/macOS 14. App target compiles App/ and depends on local package PhaseCore.

`public enum EntryKind: String, Codable, CaseIterable, Sendable { case area, phase, task, done, event, inbox }`
`public struct Entry: Identifiable, Codable, Equatable, Sendable` all fields public mutable. `id: UUID`, `kind: EntryKind`, strings `title`, `text`, `goal`, `statusNote`, `bottleneck`, `expectedChange`, `resources`, `notes`, `nextStart`; optional UUID `areaID`, `phaseID`, `taskID`; Date `date`, `createdAt`, `updatedAt`; Double `rank`, `spotlightRank`; Bool `isSpotlight`, `archived`; String `taskKind` (general/quick), `lifecycle` (active/completed/stopped). `init(kind: EntryKind, title: String = "", id: UUID = UUID(), now: Date = Date())` defaults empty, nil, 0, false, general/active. Event.text completed/stopped/reopened; event.title snapshot of task title; done.text performed content, done.notes optional. date is user's performed date, updatedAt never changes last-performed ordering.

`public struct PhaseState: Codable, Equatable, Sendable { public var entries: [Entry]; public init(entries: [Entry] = []) }`
Read API: `entry(_ id: UUID) -> Entry?`; `items(_ kind: EntryKind) -> [Entry]`; `spotlight: [Entry]`; `history(taskID: UUID) -> [Entry]` done only date descending deterministic ties; `latestDone(taskID: UUID) -> Entry?`; `resume(taskID: UUID) -> String`; `lastPerformed(taskID: UUID) -> Date?`; `isDormant(taskID: UUID, now: Date = Date(), calendar: Calendar = .current) -> Bool` at least calendar month since last performed, never recorded false; `dailyDays(calendar: Calendar = .current) -> [Date]` dates with done OR events descending, no empty dates; `doneDays(calendar: Calendar = .current) -> Set<Date>` only done dates; `areaHistory(_ id: UUID) -> [Entry]`; `phaseHistory(_ id: UUID) -> [Entry]` done+events via captured refs, descending; `markdown() -> String` full export durable content, no ids/current nextStart/ranks, no duplicate done.
Mutation API all throws `upsert(_ entry: Entry, now: Date = Date())`; `delete(_ id: UUID)` only inbox/done/event permitted (not tasks/phases/areas); `addDone(taskID: UUID?, text: String, notes: String = "", nextStart: String = "", date: Date = Date(), now: Date = Date())`; `editDone(id: UUID, text: String, notes: String, date: Date, now: Date = Date())` leaves current start untouched; `toggleSpotlight(_ id: UUID, now: Date = Date())`; `reorderSpotlight(_ ids: [UUID], now: Date = Date())`; `reorderTasks(_ ids: [UUID], now: Date = Date())`; `endTask(_ id: UUID, status: String, finalDone: String = "", now: Date = Date())`; `reopenTask(_ id: UUID, now: Date = Date())`. Validation reject blank title for task/phase/area and blank done/inbox. Snapshot refs on done/event at time performed; moving task later must not rewrite old history. end creates no done unless an explicit nonblank finalDone is supplied. Reopen does not auto-star. New star at bottom; ending removes star but retains task. All mutation atomic in value state, throw LocalizedError useful Korean message.

Persistence App/Persistence.swift parent-owned: `@MainActor @Observable final class AppStore` with `var state: PhaseState`, `var error: String?`, `var syncSummary: String`; `func apply(_ change: (inout PhaseState) throws -> Void) -> Bool` transaction save then update state, rollback on error; `func refresh()`; `var exportText: String { state.markdown() }`. UI uses `@Environment(AppStore.self) private var store`. Root `RootView()` child-owned, no App entry point. Child may add App/Views/*.swift only. Use `.sheet`, NavigationStack/NavigationSplitView, forms. All errors remain visible via root alert and don't dismiss editors on failed apply. Swift 5 language mode for Apple target; Swift 6 compiler supported.

Parent handles SwiftData Entity (@Model defaults, scalar references), app initialization, CloudKit config/sync events, xcode config/scripts and final verification.

## 알파 v2 보완 계약 (위 초기 협업 역할 설명보다 현재 사용자 승인 범위 우선)

- `Entry.linkedDoneID: UUID?` 추가: 종료 사건이 선택적 최종 Done을 가리킴. 없는 이전 JSON은 nil로 읽음. export에는 내부 연결 ID를 출력하지 않음.
- Phase의 `lifecycle`도 active/completed/stopped만 허용. `phaseStatus(_ phase: Entry) -> String`은 기존 archived=true/active를 completed로 읽기 전용 해석. `setPhaseStatus(_:status:now:) throws`는 명시적 상태 변경 시 lifecycle과 archived를 함께 변경하며 하위 Task에 손대지 않음.
- `currentTasks() -> [Entry]`는 Task lifecycle만 active로 필터하며 부모 Phase 상태/archived를 필터하지 않음.
- `endTask`의 finalDone이 공백이면 사건만 생성. 내용이 있으면 새 Done(현재 힌트는 빈칸으로 교체)과 사건을 원자적으로 저장. `recordTimeline() -> [Entry]`는 연결 Done이 존재하고 날짜가 같은 사건만 표시에서 생략하고 나머지 Done+사건을 날짜 내림차순으로 반환. 원본 이력 API/Markdown은 사건과 Done 각각 보존. `lifecycleLabel(for:) -> String?`는 결합 행의 badge용.
- `performedAreaDays(in: DateInterval, calendar: Calendar = .current) -> [AreaPerformedDays]`: 주 시작 포함/종료 제외의 Done만 캡처된 Area별 서로 다른 날짜 수로 집계. 구조체는 areaID/title/days, nil Area는 Unassigned. 사건/Task 생성/수정 시각을 활동으로 간주하지 않음.
- UI 상호작용·필터·정렬·캘린더의 전체 계약과 이유: `Docs/ALPHA-V2.md`. 기존 Task rank API는 호환용으로 유지하지만 v2 현재 Tasks의 화면 정렬은 생성일 기준. Spotlight 수동 순서는 계속 영속화.
- SwiftData revision schema, private CloudKit 경로, snapshot 소속, nextStart 교체, 저장 실패 rollback을 보존. UI 상태 AppStorage는 로컬이고 조회/필터 변경이 도메인 쓰기를 만들지 않음.
